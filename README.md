# QuickBite Marketing Analytics

## 📊 Project Overview

QuickBite is a food-delivery platform facing challenges in customer engagement, order conversion, marketing performance, and customer satisfaction.

This project uses **SQL, Python, and Power BI** to analyze customer behavior, marketing performance, conversion trends, and customer feedback to generate actionable business insights.

## 🎯 Objectives

* Analyze customer engagement and order conversion
* Evaluate marketing performance
* Analyze customer ratings and sentiment
* Identify areas for improving customer satisfaction
* Provide data-driven recommendations

## 🛠️ Tools & Technologies

* SQL
* Python
* Pandas
* NumPy
* Matplotlib
* Power BI
* Git & GitHub

## 🔍 Key Findings

* Conversion rates varied throughout the year, with January showing the strongest performance and May the lowest.
* Customer engagement declined during the second half of the year.
* Blog content generated the highest number of views.
* Customer feedback was generally positive, but the average rating of approximately **3.7** remained below the **4.0** target.
* Negative and mixed feedback highlighted opportunities to improve customer satisfaction.

## 💡 Recommendations

* Optimize marketing campaigns around seasonal conversion trends.
* Improve engagement through more effective content and calls-to-action.
* Analyze negative and mixed feedback to identify recurring customer issues.
* Focus on low-rated products and experiences to improve overall satisfaction.
